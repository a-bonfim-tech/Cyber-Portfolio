# Ransomware Incident – Healthcare Clinic (Portfolio Case)

This portfolio activity documents a ransomware incident affecting a small healthcare clinic in the United States.
The scenario is analyzed using an Incident Handler’s Journal approach, focusing on documentation, traceability, and structured incident response.

## Scope

* Incident type: Ransomware
* Initial access vector: Targeted phishing email with malicious attachment
* Impact: Loss of access to critical patient and operational data
* Sector: Healthcare (Primary Care)

## Objective

Demonstrate the ability to:

* Document a cybersecurity incident accurately
* Apply the **5 W’s of an incident**
* Maintain professional incident response records suitable for audits and compliance contexts

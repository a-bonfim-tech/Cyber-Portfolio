# Video Script — Cloud Governance & Operations (5–6 min)

## 0:00–0:30 — Intro
I operate SaaS environments with governance-first cloud operations across GCP, AWS, and Azure.

## 0:30–1:30 — Problem
Common failures: over-privileged IAM, config drift, weak observability, undocumented decisions.

## 1:30–3:30 — Method
- Least privilege by default
- SOP-driven changes
- Monitoring first, logs second, fixes last
- Templates over manual configuration
- Decisions captured via ADRs

## 3:30–4:30 — Proof
- GCP evidence with SHA-256 hashes
- Automated verification via GitHub Actions
- ADRs linked to assessments

## 4:30–5:30 — Outcome
- Faster incident response
- Audit-ready systems
- Multi-cloud scalability

## 5:30–6:00 — Close
This is how I keep cloud systems secure, observable, and governable at scale.

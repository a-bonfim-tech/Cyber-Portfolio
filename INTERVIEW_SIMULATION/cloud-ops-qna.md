# Interview Simulation — Cloud Operations & Governance

## Q1: How do you enforce least privilege?
A: Predefined/custom roles only; no primitive roles; access documented via ADRs.

## Q2: First step on a latency alert?
A: Validate scope using monitoring dashboards and correlated metrics.

## Q3: How do you investigate recurring errors?
A: Centralized logging with time/service filters.

## Q4: How do you avoid configuration drift?
A: Instance templates and infrastructure standardization.

## Q5: How do you prove competence?
A: Evidence with hashes, automated verification, and versioned decisions.

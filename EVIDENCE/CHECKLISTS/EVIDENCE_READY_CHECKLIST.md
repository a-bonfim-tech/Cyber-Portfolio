# Evidence-Ready Checklist (Cloud / Cyber)

## 1. Context
- [ ] Role clearly defined
- [ ] Platform specified (GCP / AWS / Azure)
- [ ] Scenario described

## 2. Action
- [ ] Concrete operational decision executed
- [ ] GCP service/tool explicitly named
- [ ] SOP or best practice applied

## 3. Control
- [ ] Least privilege enforced
- [ ] Standardization used (templates / policies)
- [ ] No manual configuration drift

## 4. Validation
- [ ] Post-action health check performed
- [ ] Monitoring or logs reviewed
- [ ] Outcome verified

## 5. Evidence Integrity
- [ ] Markdown artifact created
- [ ] Metadata file present
- [ ] SHA-256 hash generated
- [ ] (Optional) GPG signature created

## 6. Versioning
- [ ] Dedicated branch
- [ ] Clear commit message
- [ ] Pull Request opened

❌ If any item is unchecked → NOT evidence-ready

# Interview Case — SaaS Operations (Azure)

## Context
SaaS environment running on Microsoft Azure.
Role: Cloud / Systems Engineer.

## Challenge
Maintain governance, security, and observability across services.

## Actions (Analogous to GCP)
- Azure Blob Storage for public assets
- Azure RBAC with least privilege
- Azure Monitor dashboards and alerts
- Log Analytics for error investigation
- Patch management with health validation
- VM Scale Sets / ARM templates for standardization

## Outcome
- Governed infrastructure
- Faster incident response
- Reproducible deployments

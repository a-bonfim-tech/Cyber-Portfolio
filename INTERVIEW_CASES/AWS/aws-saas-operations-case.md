# Interview Case — SaaS Operations (AWS)

## Context
SaaS environment running on AWS.
Role: Cloud / Systems Engineer.

## Challenge
Operate secure, observable, and standardized infrastructure at scale.

## Actions (Analogous to GCP)
- S3 bucket/object management for public assets
- IAM policies with least privilege (no admin by default)
- CloudWatch dashboards and alarms for latency
- CloudWatch Logs for error triage
- Patch management with post-change validation
- EC2 provisioning via Launch Templates

## Outcome
- Consistent operations
- Reduced drift
- Audit-ready trail

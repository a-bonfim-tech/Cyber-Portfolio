# Cyber-Portfolio — Governance & Security Engineering

This repository documents my approach to cybersecurity, governance,
and security-by-design, with a focus on GDPR-aligned decision-making,
auditability, and incident handling.

## What this repository demonstrates
- Governance-first security thinking
- GDPR-aligned incident response (Arts. 5, 32, 33)
- Evidence-based decision records
- Internal audit simulation and documentation
- Security without reliance on obscurity or heroics

## Key Sections
- `governance/governance-baseline.md`  
  Authoritative governance baseline for all decisions.

- `governance/incidents/`  
  Simulated incident with full audit trail.

- `governance/decisions/`  
  Explicit decision records with GDPR grounding.

- `governance/audits/`  
  Internal audit review (hostile auditor simulation).

- `governance/evidence/`  
  Evidence handling, including intentional absence statements.

## How to read this repository
This is not a tutorial repository.
It is an audit-oriented record intended to be read top-down:

1. Governance baseline
2. Incident record
3. Decision record
4. Audit review

## Scope
This repository intentionally avoids personal data, live credentials,
or operational secrets. All content is sanitized and demonstrative.

## Status
Active — evolving as governance and security practices mature.

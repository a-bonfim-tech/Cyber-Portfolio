# 5-Minute Interview Pitch — Cloud Governance & Operations

## 1. Who I Am (30s)
I operate SaaS environments using cloud-native services with a focus on
governance, security, and observability.

## 2. The Problem I Solve (60s)
Teams struggle with:
- Over-privileged access
- Configuration drift
- Poor incident visibility

## 3. My Approach (2min)
- Least privilege IAM by default
- SOP-driven operations
- Monitoring first, logs second, fixes last
- Templates instead of manual configuration

## 4. Proof (1min)
- GCP evidence with hashes and automation
- ADRs documenting decisions
- GitHub Actions enforcing integrity

## 5. Result (30s)
- Faster incidents
- Auditable systems
- Scalable governance across GCP, AWS, Azure

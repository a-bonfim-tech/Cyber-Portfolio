# CSIRT + SOC + DevSecOps Diagram - Final Version

This PDF represents a complete hierarchical structure of a CSIRT and SOC integrated with a DevSecOps pipeline. It includes detailed labels, colors, arrows, and a legend for clarity.  

- **Executive Management (Yellow):** Stakeholders / Compliance  
- **SOC (Blue):** Analysts L1/L2, Lead L3, SOC Manager  
- **CSIRT (Green):** Security Analysts, Incident Coordinator, HR/Legal/IT/PR collaboration  
- **DevSecOps (Orange):** CI/CD pipeline, automated alerts
